# Fix: Recarga automática de tareas tras mutación en TicketDetailDrawer

## Problema
Al crear, editar o eliminar una tarea desde el panel de tareas dentro del detalle de un ticket, los cambios no se reflejan hasta que se recarga la página o se cierra y reabre el drawer.

## Causa raíz
En `TicketDetailDrawer.jsx`, los callbacks `onCreateTask`, `onUpdateTask`, `onDeleteTask` y `onUploadTaskAttachment` se pasan directamente como props a `TasksPanel` sin envolverlos para llamar a `load()` después de la mutación.

En contraste, las mutaciones de **comentarios** sí llaman a `load()` después de ejecutarse (ver línea 385 del mismo archivo).

## Solución
Envolver los 4 callbacks de tareas en `TicketDetailDrawer.jsx` para que, después de ejecutar la función original, llamen a `load()` para refrescar el estado local.

### Archivo a modificar
- `src/features/admin/components/TicketsKanban/TicketDetailDrawer.jsx`

### Cambio específico
Agregar funciones wrapper antes de la definición de `tasksTab` (línea ~1804) que combinen la mutación + `load()`:

```js
// Wrappers para refrescar tareas tras mutación
const handleCreateTask = useCallback(async (ticketId, data) => {
  await onCreateTask(ticketId, data);
  load();
}, [onCreateTask, load]);

const handleUpdateTask = useCallback(async (taskId, data) => {
  await onUpdateTask(taskId, data);
  load();
}, [onUpdateTask, load]);

const handleDeleteTask = useCallback(async (taskId) => {
  await onDeleteTask(taskId);
  load();
}, [onDeleteTask, load]);

const handleUploadTaskAttachment = useCallback(async (taskId, file) => {
  await onUploadTaskAttachment(taskId, file);
  load();
}, [onUploadTaskAttachment, load]);
```

Luego en `tasksTab` (líneas 1816-1819), reemplazar las props:
```jsx
onCreate={handleCreateTask}
onUpdate={handleUpdateTask}
onDelete={handleDeleteTask}
onUploadAttachment={handleUploadTaskAttachment}
```

## Verificación
1. Abrir un ticket en el drawer
2. Ir a la pestaña "Tareas"
3. Crear una tarea nueva -> debe aparecer inmediatamente en la lista
4. Editar una tarea (cambiar estado, prioridad, etc.) -> debe reflejarse al guardar
5. Eliminar una tarea -> debe desaparecer de la lista
6. Subir un adjunto a una tarea -> debe aparecer sin recargar
